# Ex. 11 - Database Integration in Node.js using MongoDB

Web Technology Lab (23CS2049).

Node.js program using the official MongoDB driver for insert, find, update and delete (`app.js`), plus `app-q5.js` for the sample question.

**Run:** Start MongoDB locally, `npm install`, `node app.js`.

Live page: https://noelms.github.io/Exp11_Web_Tech/

The page shows the source and output captured from a real local run; this exercise needs a local server or MongoDB, so it cannot run on GitHub Pages itself.
